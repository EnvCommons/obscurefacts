# Data Upload Requirements for ObscureFacts

## Overview
This environment requires the following data to be uploaded to OpenReward cloud storage.

## Directory Structure
```
/orwd_data/obscurefacts/
└── tasks.json (Size: ~3 KB)
```

## File Descriptions
- **tasks.json**: JSON array containing 16 trivia questions with id, question, and answer fields

## Upload Instructions
Upload `tasks.json` to the `/orwd_data/obscurefacts/` directory in the OpenReward namespace `GeneralReasoning/obscurefacts`.
